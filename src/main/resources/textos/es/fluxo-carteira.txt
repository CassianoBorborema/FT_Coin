=== FLUJO DE CARTERA ===
La cartera guarda las monedas virtuales de un titular en una corredora.
Acceda desde el menú principal: 1. Cartera.

Siempre que una operación necesita una cartera, el sistema muestra
la lista de carteras (titular y corredora) y usted elige por el
número de la lista. Use 0 para cancelar.

1. Crear cartera
   Ingrese el nombre del titular y la corredora.
2. Listar carteras
   Muestra todas las carteras, con titular y corredora.
3. Editar cartera
   Elija la cartera; el sistema muestra los datos actuales y
   pide el nuevo titular y la nueva corredora.
4. Eliminar cartera
   Elija la cartera y confirme con S. Las carteras que ya
   tienen movimientos no se pueden eliminar, para no perder
   el historial de compras y ventas.
