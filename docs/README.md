# Documentação FT_Coin

Documentação técnica do projeto FT_Coin. A referência das classes é o Javadoc, gerado com
`mvn javadoc:javadoc` em `target/reports/apidocs`.

| Documento | Descrição |
|-----------|-----------|
| [Fluxo de Carteira](fluxo-carteira.md) | Arquitetura MVC/DAO, inicialização (idioma e persistência) e cadastro de carteiras |
| [Fluxo de Movimentação](fluxo-movimentacao.md) | Compra, venda, crédito e saque, regras de saldo e vigência do crédito |
| [Fluxo de Oráculo](fluxo-oraculo.md) | Cotação simulada, histórico de cotações e consultas |
| [Fluxo de Relatórios](fluxo-relatorios.md) | Listagens, saldo, histórico, evolução diária, ganho/perda e cache da apuração |
